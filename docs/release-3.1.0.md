## Release configuration

`content/release.json` holds version, current production version, localized release title, status, optional date, download URL, feature availability and localized feature copy. Run `python3 tools/build_site.py` after edits. No browser script or assumed date changes status.

After release certification, change `status` to `available_now`, update the current version and approved feature availability/copy in that one file, then rebuild. Both pages switch their badges, release notes and CTA context together. Set an actual ISO release date only when confirmed. Feature text intentionally stays editable in the single config so final wording reflects approved scope. Generic social art does not contain a stale release status.
